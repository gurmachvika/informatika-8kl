1. Апаратна частина (Залізо) та Пам'ять

Будь-яка комп'ютерна система працює за принципами фон Неймана: вхідні дані надходять через пристрої введення, опрацьовуються центральним процесором (CPU), зберігаються у пам'яті та подаються користувачеві через пристрої виведення.

Конвеєр обробки даних у ПК

⌨️
1. Введення
Клавіатура, миша, сканер, мікрофон
⚙️
2. Опрацювання
Процесор (АЛП + ПК + Регістри)
💾
3. Збереження
RAM (тимчасова), SSD/HDD (довготривала)
🖥️
4. Виведення
Монітор, колонки, принтер

Оперативна (RAM) проти Зовнішньої (SSD/HDD) пам'яті

Головна відмінність між типами пам'яті полягає у **швидкодії** та **енергозалежності**. Оперативна пам'ять (RAM) має колосальну швидкість обміну даними з процесором, проте при вимкненні електроенергії всі дані з неї повністю стираються. Зовнішні накопичувачі (NVMe SSD, SATA SSD, HDD) забезпечують надійне та довготривале збереження файлів.

RAM (Оперативна): Енергозалежна, надшвидка. Необхідна для роботи запускних програм тут і зараз.
SSD / HDD (Зовнішня): Енергонезалежна. Зберігає вашу ОС, ігри, фотографії та документи на роки.

Порівняння відносної швидкості читання/запису (умовні одиниці / ГБ/с)

2. Операційна Система та Ієрархія ПЗ

«Залізо» без програмного забезпечення — це лише набір металу та кремнію. Програми поділяються на три основні рівні. Операційна система (ОС) виступає в ролі диригента оркестру, що зв'язує фізичні мікросхеми з прикладною роботою користувача.

Піраміда Програмного Забезпечення

Прикладне ПЗ
Браузери (Chrome), Графічні редактори (Photoshop), Ігри (Fortnite)
Системне ПЗ
Операційні системи (Windows 11, Linux, macOS), Драйвери пристроїв, Антивіруси
Апаратне забезпечення («Залізо»)
Центральний процесор (CPU), RAM, SSD, Відеокарта, Материнська плата

Орієнтовний розподіл функцій та ресурсів системного середовища

Ключові функції Операційної Системи

  • 1
    Управління процесами: Розподіляє обчислювальні такти процесора між активними програмами.
  • 2
    Управління пам'яттю: Виділяє та захищає блоки оперативної пам'яті (RAM) під кожне завдання.
  • 3
    Файлова система: Впорядковує збереження, структуру каталогу та доступ до файлів.
  • 4
    Графічний інтерфейс (UI): Забезпечує зручне віконне середовище для взаємодії людини з ПК.

3. Файлові Системи та Сумісність

Файлова система визначає спосіб організації, зберігання та найменування даних на носіях. Різні ОС використовують власні файлові системи, що впливає на їхню сумісність та максимальний розмір файлів.

Огляд популярних файлових систем

FAT / FAT32
Застаріла система від Microsoft. Використовується на простих флешках. **Обмеження:** максимальний розмір одного файлу — 4 ГБ.
NTFS (Windows)
Основна система сучасних Windows. Підтримує розмежування прав доступу, шифрування та гігантські файли.
ext4 (Linux)
Високоефективна та надійна файлова система для дистрибутивів ОС Linux та баз даних.
APFS (macOS / iOS)
Сучасна файлова система Apple, оптимізована для швидких SSD-накопичувачів та шифрування.

4. Типи Ліцензій Програмного Забезпечення

Завантажуючи програму, ви погоджуєтеся з умовами ліцензійної угоди. Ліцензія визначає ваші права на копіювання, зміну коду та оплату використання ПЗ.

Порівняльна матриця правових та фінансових атрибутів типів ліцензій

1. Freeware (Безкоштовне)
Безкоштовне для завантаження, але код закритий. Заборонено продавати чи модифікувати.
Приклади: Telegram, VLC Player.
2. Shareware (Умовно-безкоштовне)
Надається безкоштовний пробний період (наприклад, 30 днів), після чого вимагається купівля.
Приклади: WinRAR, більшість антивірусів.
3. Open Source (Відкритий код)
Вихідний код абсолютно відкритий. Будь-хто може його досліджувати, допрацьовувати та поширювати.
Приклади: ОС Linux, Blender, LibreOffice.
4. Пропрієтарне (Комерційне)
Належить розробнику. Купується лише право користування. Копіювати або зламувати код суворо заборонено.
Приклади: Windows 11, MS Office, Photoshop.

🛠️ Практична майстерня: Драйвери та Оптимізація ОС

Як розв'язувати типові проблеми з повільним завантаженням ПК та підключенням нових пристроїв.

🔌 Що таке Драйвер?

Драйвер — це спеціальна програма-«перекладач», яка вчить Операційну Систему правильно керувати конкретним новим пристроєм (принтером, відеокартою, сканером).

Пристрій введення ➔ Драйвер ➔ ОС ➔ Користувач

🚀 Оптимізація Автозавантаження

Якщо ваш ПК завантажується занадто довго, вимкніть автозапуск непотрібних програм при старті Windows:

  1. 1 Натисніть Пуск ➔ Налаштування (або Ctrl+Shift+Esc).
  2. 2 Перейдіть у розділ Програми ➔ Автозавантаження.
  3. 3 Вимкніть фонові програми (Spotify, Discord, Torrent тощо).
